# 泊冉官网风格营销页复用提示词

你是一个资深 B2B SaaS 官网设计与前端实现专家。请结合泊冉软件 `www.iboran.com` 的整体风格，为以下主题/附件/材料生成一个可以直接上线的中文营销落地页。

## 输入材料

- 公司品牌：泊冉软件 / BORAN SOFTWARE
- 目标风格：与泊冉官网融为一体，干净、专业、B2B、可信赖
- 页面主题：`在这里填写主题`
- 来源资料：`在这里粘贴文档、提纲、产品介绍或附件路径`
- 目标用户：`在这里填写行业、角色或客户类型`
- 主要转化：预约诊断 / 获取方案 / 电话咨询 / 留资表单

## 页面要求

1. 先提炼业务主张，不要把材料原文大段堆上去。
2. 页面首屏要有一个清晰承诺、一段短解释、两个 CTA。
3. 把复杂内容转成图表化结构，例如流程图、模块架构、场景卡、行业标签、对比表或 FAQ。
4. 可见文字要精简，但不能让第一次访问的人看不懂；复杂说明放进“展开详情”。
5. 视觉上沿用泊冉官网气质：白底内容区、深色首屏、蓝色品牌强调、红色 CTA、轻卡片、清晰网格。
6. 移动端必须完整适配：无横向滚动，按钮可点，表单不被底部 CTA 遮挡，导航菜单可展开。
7. 复用官网头部、底部、联系方式和导航时，必须从当前官网或本地源码提取真实文案和链接，不要凭语义猜 URL。
8. 通用市场页不要预设或推广 YonSuite、YonBIP 等具体产品线；客户可能选择不同产品或多系统集成。默认使用“业务系统 / ERP / OA / CRM / MES / 业务接口 / MCP/API / 智能问数 / 经营预警”等中性表述，除非明确要求做某个产品线专题页。
9. 行业入口不要粗暴合并。制造业和消费品必须分开：制造业强调订单交付、BOM、采购齐套、生产异常、质量追溯、成本；消费品强调渠道订单、SKU、价格政策、促销费用、门店补货、经销商对账、库存周转和毛利。

## 建议页面结构

- 固定头部：泊冉 Logo、导航、电话、主 CTA、移动端菜单
- Hero：核心业务主张、短说明、主 CTA、次 CTA、业务证明点
- 流程总览：用专业标题呈现核心闭环，例如“业务执行路径总览”或“从业务指令到系统结果的关键节点”
- 业务流程：从输入到系统落地的步骤图
- 能力架构：入口、AI、业务接口/MCP/API、业务系统、智能问数/预警、权限治理
- 样板场景：每个场景包含什么时候用、用户怎么开始、AI 做什么、系统怎么闭环、预警价值
- 行业适配：按行业给出优先试点场景
- 风险与治理：权限、审批、日志、灰度、人工确认
- FAQ：默认收起
- 诊断表单：姓名、公司、手机号、行业、当前系统或计划系统、协同工具、业务问题；系统示例保持中性，不默认绑定具体产品线
- 移动端底部 CTA：拨打电话、预约诊断、看场景

## 交付要求

- 生成静态页面：`index.html`、`styles.css`、`script.js`
- 使用现有品牌资产和相对路径
- 包含 SEO title、description、canonical、Open Graph、JSON-LD
- JS 需要通过语法检查
- 验证 390px 手机宽度无横向溢出
- 验证所有外链/官网深链不是 404 或空页面
- 最后说明修改了哪些文件，以及验证结果

## 后台与发布注意

- 泊冉官网后台通常是 Payload CMS，但后台能登录不代表所有页面文案都能编辑。
- 如果某句话不在对应 collection、global 或 API 数据里，应判断为前端源码静态文案，需要修改源码并重新部署。
- 不要在未确认前保存、发布、删除或修改线上后台数据。
