# 内容依据与来源说明

## 1. 内部资料依据

本素材吸收了以下三类方法论资料的核心内容：

1. YonSuite 公有云 SaaS 实施方法论：用于支撑中小型 / 成长型客户的快速上线、标准产品优先、智能交付工具、CSM 移交、持续运营等口径。
2. YonBIP 敏捷交付方法论：用于支撑大中型 / 集团型客户的售前评估、筹建准备、蓝图设计、系统建设、上线切换、持续运营、项目管理、A/B 类工具、领先实践资产等口径。
3. AI 赋能实施效能培训资料：用于支撑 AI 在实施、集成、运维、迁移服务中的辅助定位，即资料助理、初稿顾问、风险检查员。

## 2. 公开信息依据

公开信息主要参考以下能力方向：

- 用友客户成功服务体系：服务产品、AI 服务、服务工具、服务赋能、服务获取；服务工具包括数据抽取、数据同步、移动审批、BIP 升迁、数据脱敏、云巡检、更多服务工具。
- YonSuite 客户成功服务：标准、加速、优先、尊享客户成功计划，以及操作手册、FAQ、培训视频、管理员赋能、工单跟踪、应用健康度评估、系统运营报告、关键时刻支持等服务项目。官网客户支持菜单中的辅助入口不作为本服务网站主体模块展示。
- 用友开发者中心：API 网关、数据集成、集成总线、YonBuilder 低代码、YonMaker 生态定制等公开能力。

## 3. 内容处理原则

- 网站文案采用“学习借鉴 + 服务体系重构”的方式，不直接复制官网页面结构。
- 不使用用友官网图片、Logo 或版权素材。
- 保留 YonSuite、YonBIP、NC、NCC 等产品名称，是为了表达服务适用场景；实际上线前应确认品牌使用权限和合作资质。
- “AI 赋能”只能表达为辅助，不应表达为自动替代顾问、自动承诺客户、自动交付。
- “安全、知识、合规”只转化为安全巡检、补丁管理、权限检查、备份恢复、操作手册、FAQ、培训视频、管理员赋能和 AI 边界说明，不显性展示官网辅助入口名称。

## 4. 术语建议

| 推荐术语 | 不推荐术语 | 说明 |
|---|---|---|
| 系统运维与客户成功服务 | 售后客服 | 更能体现持续运营价值 |
| 集成与开发服务 | 二次开发 | 范围更完整，包含 API、数据集成、低代码、客开 |
| 迁移与工具服务 | 迁移工具 | 覆盖抽取、同步、升迁、脱敏、巡检、备份等 |
| 大中型 / 集团型客户 | 大客户 | 更专业，避免口语化 |
| 中小型 / 成长型客户 | 小客户 | 更正向，强调成长阶段 |
